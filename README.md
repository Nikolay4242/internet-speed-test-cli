Internet Speed Test CLI

Консольный скрипт на Python для замера реальной скорости скачивания из интернета. Скрипт выполняет последовательные HTTP-запросы к указанному ресурсу, избегая чрезмерного потребления оперативной памяти за счёт потоковой загрузки (streaming).

Единицы измерения
В результатах используются две стандартные единицы измерения (указаны в итоговом выводе):
- **Мбит/с (Мегабит в секунду, Mbps)** – стандартная единица, которую используют интернет-провайдеры для указания скорости тарифа (1 Байт = 8 бит).
- **МБ/с (Мегабайт в секунду, MB/s)** – привычная единица для оценки реальной скорости записи на диск или скачивания файлов в браузере.
